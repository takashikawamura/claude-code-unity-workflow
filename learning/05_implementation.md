# 05. 実装・検証

## Step 4: 実装・検証

### 実装

- プランから実装する（承認したプランを必ず参照）

### テスト

スキル: `/test-unity`

| テストモード | 内容 |
|---|---|
| **EditorMode** | Unity Editor 内で実行、MonoBehaviour 不要なロジックのテスト |
| **PlayMode** | ゲームの実行状態をシミュレート、MonoBehaviour のテスト |

**EditorMode と PlayMode を適切に区別する** ことが重要。

### レビュー

スキル: `/lint-unity`

#### コードレビューのタイミング

| タイミング | メリット | デメリット |
|---|---|---|
| Push 前 | 早期発見 | トークン消費が激しい |
| Push 後（PR で） | 推奨 | 後で対応が必要 |

#### Push 前にやらせる場合

別エージェントを使うとよい：
- Codex
- Antigravity
- GitHub Copilot

Claude にやらせる場合は**別コンテキスト**で行う（同じコンテキストだとバイアスがかかる）。

#### Unity 特有のチェック

コード以外の Unity ルール違反も確認する：
- ヒエラルキーの構造
- ファイル命名規則
- シーン・Prefab の構成
