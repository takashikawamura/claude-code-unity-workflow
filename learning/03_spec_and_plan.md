# 03. 仕様書作成・プラン作成

## Step 0: 仕様書の作成（TA の場合）

### TA が書く仕様書の内容

プログラム仕様ではなく、**ビジュアル仕様**を書く。

```
## エフェクト仕様: 炎の柱エフェクト
- 見た目: 下から上に向かって伸びる柱状の炎
- サイズ: 高さ 3m、幅 0.5m
- 色: 根本はオレンジ（#FF6B00）、先端は白に近い黄色
- アニメーション: 2秒でループ、乱流感のある揺れ
- パフォーマンス: モバイル対応（GPU パーティクル 500 以下）
- 使用ツール: VFX Graph
```

Claude はこの仕様を読んで、実現方法やノード構成の提案ができる。

### PlanMode でプランを作成する

必ず **PlanMode** でプランを作成してから制作に入る。

```
「炎の柱エフェクトを VFX Graph で作りたい。一緒に考えましょう」
```

Claude が `AskUserQuestion` で確認を取りながらプランを練り上げる。

### プランに含まれる内容（TA の場合）

- 使用するノードの構成案
- 参考にすべきエフェクトや手法
- パフォーマンスに関する注意点
- アセットのフォルダ構成・命名案
- 作業ステップの分割

## Step 1: プランの承認

### 承認前に確認すること

- [ ] ビジュアルの方向性が意図と合っているか
- [ ] 提案されたアプローチが自分の理解の範囲か（分からなければ質問する）
- [ ] パフォーマンス要件が考慮されているか
- [ ] 作業範囲が適切な粒度か

**脳死で OK するな** — 承認 = あなたがその内容に責任を持つということ。

### 実装方針の確認方法

```
「一般的な VFX Graph でのアプローチ」と「このプロジェクトへの Claude の推奨」を
2つ聞いて自分で判断する
```
