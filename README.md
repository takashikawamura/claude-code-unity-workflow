# ClaudeCode x Unity 開発ワークフロー 学習教材（TA・CGデザイナー向け）

@ooba の技術シェア資料をもとに、**テクニカルアーティスト・CGデザイナー視点**で再構成した学習教材です。

> C# プログラミングではなく、VFX Graph / Shader Graph / アセット制作・シーン構築を主な業務とする方向け。

## 構成

```
learning/
  01_overview.md          前提・環境・必要ツール
  02_workflow_overview.md ワークフロー全体像（TA視点）
  03_spec_and_plan.md     仕様書作成・プラン作成
  04_issue_and_branch.md  Issue作成・ブランチ作成
  05_ta_workflow.md       TAとしての制作フロー（主軸）
  06_vfx_shader.md        VFX Graph / Shader Graph での活用
  07_commit_review.md     コミット・レビュー（アセット編）
  08_team_rules.md        Rules / Skills / Hooks
  09_tips.md              Tips・まとめ

checklist/
  checklist.md            学習チェックシート
```

## 学習の進め方

1. `learning/` を 01 から順番に読む
2. **05・06 が TA にとって最重要** — 繰り返し読む
3. `checklist/checklist.md` で自己確認
4. 実際に手を動かして体験する
