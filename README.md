# ClaudeCode x Unity 開発ワークフロー 学習教材

@ooba の技術シェア資料をもとに作成した学習教材です。

## 構成

```
learning/
  01_overview.md          前提・環境・必要ツール
  02_workflow_overview.md ワークフロー全体像（9ステップ）
  03_spec_and_plan.md     仕様書作成・プラン作成
  04_issue_and_branch.md  Issue作成・ブランチ作成
  05_implementation.md    実装・検証
  06_commit_push_pr.md    Commit → Push → PR
  07_code_review.md       コードレビュー・レビュー対応
  08_team_rules.md        Rules / Skills / Hooks
  09_parallelization.md   Unity開発の並列化
  10_testing.md           テスト方法
  11_tips.md              Tips・まとめ

checklist/
  checklist.md            学習チェックシート
```

## 学習の進め方

1. `learning/` を 01 から順番に読む
2. 各セクションを読んだら `checklist/checklist.md` で自己確認
3. 実際に手を動かして体験する
